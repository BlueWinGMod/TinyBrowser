# TinyBrowser
The lightest Android browser in existence (lighter than Naked Browser).
The Features
 * Ultralight: Only 3Ko raw and the real source code is only ~600 bytes (8KB when signed).
 * Privacy by Design: Zero history, zero tracking, 100% FOSS.
 * Accidental Ad-Blocker: No JavaScript means zero ads on news sites !
 * The Tilt Trick: Just rotate your device to go back to the homepage it's amazing but turn on autorotate before !
 * Universal: Supports every android from 5-17 but there is an legacy version and works from android 1-7  flawlessly on tablets.
